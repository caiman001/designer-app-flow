## 写法规则（换任何 App 都成立）
- **一件事一个词**：同一个概念全 App 只用一个词；同字不同义（标题「新建」vs 动作「添加」）拆成两个 key
- **标签短**：中文 ≤ 4 字、英文 1–2 个词；放不下先改短，不缩字号
- **日期、数字、单位用系统格式**（`formatted()`），不手拼「10-12」；小数点、千位分隔跟地区走（数字输入框初值不带千位分隔，见 LESSONS）
- **复数**：英文单复数用 String Catalog 的 plural 变体（字里要带数字）；只显示单位不显示数字的拆成 `.one` / `.other` 两条 key；一句两个参数又要分单复数用 substitutions
- **源语言表每条写全**，否则缺的 key 会掉进回落语言
- **繁中**：用台湾 / 香港通行的说法，不是简体逐字转（`StringTransform("Hans-Hant")` 只能当初稿，要逐条核）；外国国名用大陆译名的繁体（CLAUDE.md 硬约束 9）
- **读屏**（accessibilityLabel）也要翻；数值读成人话（「1 比 16」不是「1:16」）
- **用户数据不翻**：名字等传 `.verbatim(…)`，不当 key
- **改了通知等「已经发出去」的文案 key**：旧 key 留着，老版本排好的还要用
- 系统层也要翻：App 名（`CFBundleDisplayName`）、权限文案、快捷指令短语、商店文字（APPSTORE-LISTING）
