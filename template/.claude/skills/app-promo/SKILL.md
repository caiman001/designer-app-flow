# {App名} 宣发生产

**统一的是底层风格，不是长相。** 每一篇的构图、镜头、手机怎么摆、用哪几样元素，都按这一篇的内容重新设计；上一期只是例子，不是模板。

## 宣发内容放哪
总入口 `marketing/README.md`（定位、平台、日历、复盘）；每期一个文件夹 `marketing/episodes/<期号-短名>/`：brief.md 策划 / copy.md 各平台文案和 tag / metrics.md 数据 / final/ 成片和封面。
**做新一期前先读 README 和上一期的 brief、metrics**；出片后把成片、封面复制进这期的 `final/`，文案和数据回填。记数据、排日历、起草策划交给 agent `{app}-marketing`。

## 0. 顺序（别跳）
1. **先在 Design 画布上规划**：分镜 / 关键帧 / 版式，按成片真实尺寸排（视频 1080×1920、封面 1080×1440，缩 1/3 排），每张下面写动作和声音
   - **先出完整分镜**（每一帧都有画面 + 动作 + 声音），不要只给几张关键帧代替分镜；分镜认可后再做 3–4 秒动态小样看手感
   - 每篇给 2–3 个**构图方向**让用户挑，都在同一套视觉语言里
2. 用户确认后才写生产脚本、录屏、出片。「直接做」= 不用再问要不要做，**不是**跳过规划
3. 截图永远不能当设计稿

## 1. 视觉语言（第一期定下后填；之后每篇都守）
- **调性**：
- **颜色**：（用 App 自己的颜色；一张图一个强调色）
- **底**：视频 / 封面各用什么底（渐变 + 颗粒底容易显得有 AI 感）
- **字**：视频标题 / 封面标题 / 数字 / 说明标签各用什么字体
- **元素工具箱**：（每张挑 1–2 样，别全上）
- **样机**：只用 Apple Design Resources 官方机身 + 真实截图（3 倍）；机身实心、不切边、四角干净（屏幕遮罩要 RGBA 带透明通道，灰度遮罩不生效会露出方角）
- **用户否掉过的（别再提）**：

## 2. 动效（视频）
- 真实界面为主：App 自己的动效就是看点，别加景深 / 浮起 / 重画 App 界面
- 可选「仿录屏」：底图用 App 真实截图（模拟器 Release + 虚构示例数据），动效自己做——节奏可控
- 转场用同一个元素接；节奏从容，动作之间留呼吸；结尾统一落到图标 + 字标（系列签名，每期一样）
- 点击处一个淡白触点，拖动时触点贴着被拖的东西走

## 3. 社媒版式规则（所有素材）
- **每期按平台出版本**：小红书中文 9:16 + 3:4 中文大字封面；IG 英文 9:16 + 9:16 封面（避开上 220 / 下 420 / 右 150）；X 英文 4:5 + 第一帧放钩子。规格表放 `marketing/accounts.md`
- 9:16 安全区：顶部 ~270 平台栏、底部 ~420 头像 / 文案（文案长会升到 ~670）、右侧 y>1150 点赞栏：要读的字放 x 96–960、y 300–1250
- 网格缩略图按 3:4 / 4:5 / 1:1 裁：封面主体收在中间
- 正文字号 ≥ 34px（≈ 手机 12pt）

## 4. 音效
- 只给「有东西碰到东西」的瞬间配声；需要节奏的片子可以配乐（精致、克制，不要网红口水歌和人声），动作踩在拍子上
- 和 App 里的真实声音同一套（App 有音效就用同公式生成）
- 响度：归一 -18 LUFS 再 ×0.7（-18 在手机上听偏响）

## 5. 生产流程（每期一个 `design/promo/p<N>/`）
1. App 调试版加一个「宣发导演」启动参数：自动走剧本、打点（每一步的时刻写进 log）
2. 录屏：状态栏 9:41、浅色；**录的时候用模拟器工具真滑真点**，每步之后看 log 确认生效再做下一步，一步没生效就整条重录；先关掉残留的 `simctl io … recordVideo`（否则「Host recording is already in progress」）
3. 预处理：转 60fps、按打点自动生成剪辑表
4. 合成：网页场景 + 无头 Chrome 逐帧截图 → ffmpeg；先抽几帧检查
5. 音效脚本 → 合成成片
- 检查：抽帧拼条看节奏、放大看机身四角
- 录屏、成片在 raw/ out/ build/，不进 git

## 6. 发布
- 文案用户自己写，只帮润色：口语、短句、真实细节，不排比、不用破折号
- 发完守 30–60 分钟回评论（用户自己回）
- 话题：小红书 10 个（大 2 + 中 5 + 小 3，发布页输 # 看浏览量再替换）；IG ≤5 个精准词；X 1–2 个（#buildinpublic）
- 原创声明开；用了 AI 生成图就勾「包含 AI 合成内容」
